# Newspaper Article Page

A project focused on advanced CSS Typography, exploring the relationship between root font sizes and relative units (em/rem).

## 🚀 Features

- **Typography Hierarchy:** Implemented a complex font system using 'Open Sans' for readability and 'Times New Roman' for a classic newspaper feel.
- **Relative Scaling:** Used a combination of `rem` (root-based) and `em` (parent-based) units to create a scalable design.
- **Drop Caps:** Styled the first letter of each paragraph using the `::first-letter` pseudo-element for a professional editorial look.
- **Semantic HTML:** Used proper heading levels (h1-h3) to ensure a logical document structure.

## 🛠️ Tech Stack

- **HTML5:** Semantic article structure.
- **CSS3:** Advanced typography properties (`text-indent`, `line-height`, `text-transform`), and Pseudo-elements.

## 💡 Key Learnings

1. **Relative Units:** Mastering the difference between `em` (context-dependent) and `rem` (global-dependent) font sizes.
2. **First-Letter Styling:** Learning how to enhance readability and visual appeal using pseudo-elements for editorial effects.
3. **Inheritance:** Understanding how font properties flow from the `html` root to nested containers like `.newspaper`.
